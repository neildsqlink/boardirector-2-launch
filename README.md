# Boardirector 2.0 — launch deck

The deck for the Boardirector 2.0 launch: an opening film, then each feature with a short demo.
Hebrew, right-to-left, 1920×1080.

**Open it:** https://neildsqlink.github.io/boardirector-2-launch/

**Controls:** click or → / ↓ / Space for the next step, right-click or ← / ↑ to go back. During the
opening film: Space pauses, S skips, R restarts, M mutes. The feature bar at the top jumps to a feature.
B shows the speaker notes.

All names in the screens are fictional. Music: "Vibrant Days" by AlexGrohl (Pixabay licence).

Run it locally: `npm install` then `npx vite`, and open `/v2.html`.
